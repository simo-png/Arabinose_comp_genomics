# History

A running log of decisions and changes made to this project, in chronological order.

Goal: group the Actinobacteria genomes (`lipid_genomics/actinos/genomes`, 252) by taxonomy, compute presence of the vnz/Ara (lacI-AraR, AraB, AraA, AraD) and SCO (SCO2401, 2402, 2403, 2407, 2439, 2440) pathway genes from the `hmm_search` results, and plot a heatmap next to the grouped tree.

## 2026-09-26

- Created the directory (`config/`, `scripts/`, `data/`, `results/`).
- Grouping rank: **order**. NCBI has dropped most Actinobacteria suborders (they were raised to orders); e.g. Dermatophilaceae (taxid 85018) goes straight from order Micrococcales to the family, with no suborder node.
- Wrote `scripts/01_get_taxonomy.py`: reads genome, assembly and taxid from `lipid_genomics/actinos/COG0236_ACTINOMYCETOTA.tsv` and fetches class/order/family/genus with the `datasets` CLI (`envs/ncbi_datasets`), in batches of 25 taxids. One call for all taxids was very slow (minutes, stopped); a single taxid takes ~2 s. Raw batch answers are cached in `results/taxonomy/raw/` so an interrupted run resumes.
- Ran it (~3.5 min, 11 batches). Result: 253 genomes in 6 classes and 32 orders, see `results/taxonomy/order_counts.tsv`. Micrococcales dominates (93); 13 orders have only 1–2 genomes.
- Fix: *Herbiconiux* SALV-R1 has an outdated taxid in the input table (2735133, merged into *Herbiconiux salviae* 3092664). NCBI answers under the new id and lists the old one in `secondary_tax_ids`; the script now maps both.
- Note: the input table has 253 genomes but `lipid_genomics/actinos/genomes/` has 252 — `Allobranchiibius_GilTou73` has no genome folder.
- Wrote `scripts/02_group_by_order.ipynb`: loads `order_counts.tsv` and `taxonomy_orders.tsv` and maps each genome to its HMM (`.tblout`) name. The HMM-results part is being added step by step.
- Name lookup: the taxonomy uses COG-table genome names (= `actinos/genomes/` folder names), while `.faa`/`.tblout` files are named after the organism in each genome's GenBank file (`gbk_to_faa.py`); these differ for most genomes. Mapped via the `.gbff` `ORGANISM` line (continuation lines joined, square brackets removed): 252/253 matched; `Allobranchiibius_GilTou73` has no genome folder and no HMM results.
- `02_group_by_order.ipynb` now: orders with >= 9 genomes plus Kitasatosporales (always kept), order x gene contingency of genomes with a passing hit (`status == "pass"` from `hmm_search/results/actino_top_hits_after_synteny.tsv`), and an order tree + heatmap figure.
- Order tree: from the old whole-genome tree (`lipid_genomics/actinos/output_WGS_tree_actinos/faa.tre.treefile`), **midpoint-rooted** (separates Coriobacteriia from all other classes) until the tree with outgroups is ready; each order collapsed to one tip, drawn as a cladogram. Tips matched to genomes on letters/digits only (IQ-TREE turned `[ ] ( ) =` into `_`); all 252 tips matched. Micrococcales is not one clade (all 14 Actinomycetales sit inside it) — marked `*`.
- Kitasatosporales (8 genomes, 2 *Streptomyces*) is replaced by two rows from the Streptomycetae genome set combined with it: **Streptomyces (n=194)** and **other Streptomycetaceae (n=17)**. New export cell in `hmm_search/scripts/selection_criteria.ipynb` writes `hmm_search/results/strep_top_hits.tsv` (best hit per genome/model, same thresholds, pass/fail only — no synteny soft passes for this set). Genomes in both sets counted once (*K. setae* KM-6054, *P. bronchialis*, *S. cattleyicolor*, *S. coelicolor* A3(2)); added from the Actinobacteria set: *A. bryophytorum*, *Streptacidiphilus* sp. P02-A3a, *S. griseus* NBRC 13350, *Yinghuangia* sp. ASG_101. *[Kitasatospora] papulosa* counted as *Streptomyces*. "other Streptomycetaceae" is not one clade — marked `*`.
- First look: SCO genes are present in ~2/3 of *Streptomyces* (98–130 of 194) but rare elsewhere (Micromonosporales, Pseudonocardiales, a few other Streptomycetaceae); AraB/A/D are widespread across Actinomycetes; lacI-AraR rarely passes outside Streptomycetaceae (threshold may be too strict for distant orders — to check).
